# Model Development Lab

The public project recreates safe, generalizable model-development patterns:

- temporal train/calibration/holdout splits;
- label maturity and delayed-snapshot filtering;
- as-of history features that cannot see future events;
- feature-family ablations;
- calibration comparison;
- synthetic cohort diagnostics;
- shadow-model comparison before promotion.

The production source that inspired these patterns is intentionally not copied. All data and features in this repo are synthetic and generic.
